# Contributing to NebOs

Thank you for your interest in NebOs! This operating system is a community-driven project built on transparency, user ownership, and strict protection against predatory AI practices. By submitting a Pull Request (PR), you agree to the following rules and licensing terms.

## AI Usage & Code Tagging Rules

Scribbling or assisting with AI is allowed, but human ingenuity must remain the core of NebOs.

1. **The 50% AI Cap:** If code generated by artificial intelligence (LLMs) constitutes more than 50% of your total Pull Request lines of code, the PR will be automatically rejected.
2. **Mandatory Inline Tagging:** You MUST explicitly mark the boundaries of human and AI code using the following strict comment structure:

```c
// this part was made by <YOUR_NICK>:
void human_written_code() {
    // Your actual code here
}
// the following isn't made by <YOUR_NICK>

// this is made by <MODEL_NAME>:
void ai_assisted_code() {
    // Code generated by an ALLOWED AI model
}
// <MODEL_NAME> didn't write the following
```

*Note: PRs missing these tags or using unauthorized AI models (e.g., OpenAI/ChatGPT) will be closed instantly.*

## Copyright Transfer & Contributor Agreement (CLA)

By submitting and merging a Pull Request into the NebOs repository, you agree to the following Contributor License Agreement:

1. **Copyright Assignment:** Upon the merging of your PR, all proprietary and copyright-like economic rights of the submitted code—both human-written and AI-generated—are permanently, irrevocably, and globally transferred to the main creator of NebOs (mikx049).
2. **What You Get:**
   - **Contribution Credit:** Your name/nick will be permanently added to the CONTRIBUTORS.md file and inside the source history.
   - **Discord Role:** You will receive the exclusive "Contributor" rank on our official Discord server, granting access to core developer channels.
